**Goal:** Add 2048 as the second playable game in the static mini-games collection.

**Architecture:** Keep the current static-site structure. The 2048 rules live in a CommonJS/browser-compatible `game-state.js` so Node tests can cover movement, merging, scoring, win, and game-over behavior; `game.js` only handles DOM rendering, keyboard input, touch input, and local storage.

**Tech Stack:** Static HTML, shared CSS, vanilla JavaScript, Node-based tests, Nginx deployment script.
