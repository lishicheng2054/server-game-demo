# Remote Merge Practice

This file was added on the `feature/remote-merge-demo` branch to practice the GitHub Pull Request workflow.

Practice flow:

1. Commit this file on the local feature branch.
2. Push the branch to GitHub.
3. Open a Pull Request from `feature/remote-merge-demo` into `main`.
4. Merge the Pull Request on GitHub.
5. Pull the updated `main` branch back to the local repository.
