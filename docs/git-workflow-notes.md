# Git Workflow Notes

This project is used to practice a simple GitHub workflow:

1. Initialize the local repository and create the first commit.
2. Create a feature branch for a small change.
3. Merge the feature branch back into `main` locally.
4. Push `main` and future branches to GitHub.
5. Use a GitHub pull request to practice remote merging.

Keep private deployment keys and local environment files out of Git history.
